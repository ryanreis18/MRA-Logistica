# Descrição 

Este projeto está sendo desenvolvido como um aplicativo focado em logística para ajudar pequenos comércios, utilizando a biblioteca ____ para construir interface com informações sobre o cliente, local, motorista, veículo e carga.

# Funcionalidades

* Página inicial com motoristas cadastrados e mapa
* Página de negociação, acessível ao clicar no perfil de um motorista para negociar
* Chat entre motorista e cliente
* Suporte 24h
* Roteirização
* Rastreamento em tempo real
* Gestão de Inventário e Armazenagem
* Logística de Transporte e Frota
* Arquitetura Técnica
* Segurança aplicada
